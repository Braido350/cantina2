# Cantina

Web app to manage orders and inventory for school canteens and community events.

> 🚧 Work in progress — rewrite of [cantina](https://github.com/Braido350/cantina) with Next.js and TypeScript.

## Features (in progress)

- **Product management** — add, edit and remove products and stock
- **Customer management** — register customers and track who ordered what
- **Orders** — record customer orders
- **Sales reports** — overview of what was sold

## Tech stack

- [Next.js](https://nextjs.org) (App Router) + React
- TypeScript
- Tailwind CSS + Radix UI components
- React Hook Form + Zod for form validation

## Getting started

```bash
git clone https://github.com/Braido350/cantina2.git
cd cantina2
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
